---
title: "Advanced Installation"
description: "Manual installation using your own system PostgreSQL 16+ and MinIO binary."
---

Use **Advanced mode** (`npm run setup -- --advanced`) for large production deployments, managed PostgreSQL instances, or hosts where PostgreSQL and MinIO are already managed as separate system services.

## Prerequisites

1. **Node.js 20+** and **git**
2. **PostgreSQL 16+** running and reachable (with `pgcrypto` extension support)
3. **Official MinIO binary** (`RELEASE.2025-09-07T16-13-09Z`) in `./bin/minio` (or `./bin/minio.exe`), or let the installer download and verify it for you

## Manual MinIO Binary Download & Verification

> Note: `dl.min.io` was retired (`410 Gone`). Download from official GitHub Releases (`RELEASE.2025-09-07T16-13-09Z`) and verify the `.sha256sum`:

- **Windows x64**: `https://github.com/minio/minio/releases/download/RELEASE.2025-09-07T16-13-09Z/minio.windows-amd64.RELEASE.2025-09-07T16-13-09Z.exe`
- **Linux x64**: `https://github.com/minio/minio/releases/download/RELEASE.2025-09-07T16-13-09Z/minio.linux-amd64.RELEASE.2025-09-07T16-13-09Z`
- **Linux arm64**: `https://github.com/minio/minio/releases/download/RELEASE.2025-09-07T16-13-09Z/minio.linux-arm64.RELEASE.2025-09-07T16-13-09Z`

## Running the Advanced Installer

```bash
git clone https://github.com/Pratyush-Nirwan/patchwork.git
cd patchwork
npm ci
npm run setup -- --advanced
```

In Advanced mode, the installer connects to your existing PostgreSQL server, provisions the database/role, verifies MinIO (or downloads it if you choose "Install MinIO for me"), generates `.env`, and optionally installs `deploy/patchwork.service` and `deploy/minio.service` on Linux.
