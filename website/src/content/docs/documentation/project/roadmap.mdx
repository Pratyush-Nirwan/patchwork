## Known Limitations in v0.7.1-beta

The following capabilities are **not yet available in v0.7.1-beta**, are **planned for v1.0.0**, and are tracked in the tables above:

- **Email notifications and SMTP delivery**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#collaboration-and-notifications).
- **In-app notification inbox**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#collaboration-and-notifications).
- **Standalone audit log viewer**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#security-audit-and-operations).
- **Personal API tokens (PATs) and public REST API**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#git-and-developer-integrations).
- **Inbound and outbound webhooks**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#git-and-developer-integrations).
- **2FA, passkeys, and SSO / OAuth login**: Not yet available in v0.7.1-beta. Planned for v1.0.0. See the [Roadmap](#security-audit-and-operations).

### Out of Scope (Not on the Roadmap)

- **Docker / container images**: Patchwork is intentionally native-only on Windows and Linux.
- **Native desktop or mobile apps**: Patchwork is a responsive web application for desktop and mobile browsers.
