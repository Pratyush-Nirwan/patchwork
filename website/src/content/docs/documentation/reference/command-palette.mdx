#### `/new`

- **Usage:** `/new title column:column priority:level assignee:@user label:tag`
- **Minimum role:** `member`
- **Aliases:** `/create`
- **Arguments:**
  - `title` (ticket title, required): Type the title. Add options like priority: high after it.
- **Options:**
  - `column:column` (example: `In Progress`): Target column on the active board
  - `priority:level` (example: `high`): Ticket priority (urgent, high, medium, low)
  - `assignee:@user` (example: `me`): Assign to a team member or me
  - `label:tag` (example: `bug`): Comma-separated label tags
- **Examples:** `/new title: Fix SSE reconnect priority: high`, `/new title: Audit login rate limit`
