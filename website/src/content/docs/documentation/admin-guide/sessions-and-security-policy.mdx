## Password Policy

Configure in `SecuritySettingsSchema` (`src/lib/settings.ts`):

- **Minimum length** (`passwordMinLength`): `6` to `128` characters (default: `8`).
- **Character requirements**: Toggle `passwordRequireMixedCase`, `passwordRequireDigit`, and `passwordRequireSymbol`.

## Session Lifetime & Idle Timeout

- **Session Lifetime** (`sessionLifetimeMs`): Maximum cookie/session age (minimum `60000` ms; default `7` days).
- **Idle Timeout** (`sessionIdleTimeoutMs`): `0` (disabled, default) or `60000` ms (1 minute) up to `30` days. When an idle session expires, API requests return `401 SESSION_IDLE_EXPIRED`, the client preserves any in-progress draft input, displays the session-expired prompt once, and restores state on re-login.

## Login Rate Limiting

- **Max Failures** (`rateLimitMaxFailures`): `1` to `100` failed attempts (default: `5`).
- **Window** (`rateLimitWindowMs`): `1000` ms to `24` hours (default: `15` minutes).

## Expected Result

Updated policies apply immediately to subsequent logins, password changes, and active session validations.
