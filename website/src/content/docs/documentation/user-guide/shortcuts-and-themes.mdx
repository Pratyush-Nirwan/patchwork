This guide is for all signed-in users (`admin`, `lead`, `member`, `viewer`).

## Keyboard Shortcuts

- Press `?` anywhere outside text inputs to open the **Keyboard Shortcuts** modal.
- Rebind any shortcut (`Open Command Bar`, `Command Bar Help`, `New Ticket`, `Toggle Sidebar`, `Keyboard Shortcuts`) or reset to defaults.
- Custom shortcuts persist per user.

See [Command Palette & Shortcuts Reference](/documentation/reference/command-palette/) for default bindings on Windows/Linux and macOS.

## Themes & Appearance

- Switch between **Light**, **Dark**, and **System** themes in Account Settings or by running `/theme light|dark|toggle` in the Command Bar.
- Theme changes apply immediately across the workspace and persist in `localStorage`.

## Account Settings

Open **Account Settings** from the user profile menu at the bottom of the left navigation rail to update your display name, password, theme preference, and keyboard shortcuts.

## Expected Result

Shortcut bindings and theme preferences take effect immediately without reloading the page.
