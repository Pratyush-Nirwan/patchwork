This guide is for organization administrators (`admin` role) managing accounts in **System Configuration -> Users & Access** (`/dashboard/system/users`).

## Adding & Importing Users

- **Single user**: Click **Add User**, enter name, email, and initial role, and share the generated temporary password. New accounts have `mustChangePassword` enabled.
- **CSV Import**: Upload a CSV file to create multiple accounts at once. Duplicate or case-variant emails (`User@example.com` vs `user@example.com`) are rejected with row-level feedback.
- **CSV Export**: Export the current directory (`sanitizeFilename()` enforced on download).

## Editing, Resetting & Deactivating

- **Edit details & roles**: Update display name, org role (`admin`), or team roles (`lead`, `member`, `viewer`, and `developer`/`tester` sub-roles).
- **Reset password**: Generates a new temporary password and flags `mustChangePassword` on next sign-in.
- **Force sign-out**: Invalidates all active rows in `sessions` for that user immediately.
- **Deactivate / Reactivate**: Prevents login without deleting ticket history or comments.

## Bulk Actions & Deletion

Select multiple users to run bulk deactivation, reactivation, or team assignment. Permanent deletion of deactivated accounts is available in **Danger Zone** (`/dashboard/system/danger-zone`).

## Expected Result

Account status, role updates, and forced sign-outs take effect on the user's next API request.
