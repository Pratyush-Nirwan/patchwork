# Slash Command Fixes Plan

## Scope & Constraints
- Fix the 10 UX, keyboard, formatting, feedback, confirmation, help, and history issues in the Patchwork Spotlight-style command bar (`CommandPalette.tsx`, `ui/command.tsx`, `parser.ts`, `registry.ts`, `route.ts`, `PatchworkApp.tsx`).
- No Docker, no new dependencies, no permission/API/data-model changes, no new commands, no logging of command arguments or ticket content.
- Single source of truth for usage/help/error formatting via `formatUsage(command)` in `src/lib/commands/registry.ts`.
- Shared parser module `src/lib/commands/parser.ts` used by both client (`CommandPalette.tsx`) and server (`src/app/api/commands/execute/route.ts`).

## Product Decisions & Safest Defaults
1. **Navigation vs Snackbar commands**:
   - Navigation / UI-opening commands (`open`, `go`, `view`, `filter`, `sidebar`, `members`, `settings`, `system`, `help`, `logout`) close immediately and show no snackbar.
   - Mutation / state-changing / info commands (`new`, `move`, `assign`, `priority`, `label`, `due`, `comment`, `link`, `archive`, `delete`, `column`, `theme`, `me`) close the palette and display a 5-second app-level snackbar (`aria-live="polite"`, pausable on hover/focus).
2. **Undo support (using existing APIs only)**:
   - Reversible commands define an Undo action in the snackbar: `/move` (moves back to previous column), `/assign` (restores previous assignee), `/priority` (restores previous priority), `/label` (restores previous labels), `/due` (restores previous due date), `/theme` (restores previous theme).
   - `/new` includes an **Open** action that selects the newly created ticket.
   - `/delete`, `/archive`, `/comment`, `/link`, `/column`, `/me` show the snackbar without Undo (no API changes).
3. **Destructive ticket context lookup**:
   - Before showing the confirmation banner for `/delete` or `/archive`, look up the ticket via existing permissioned endpoints (`GET /api/search?q=<key>` + `GET /api/tickets/<id>`), falling back to the active board's `tickets` list if already loaded, and show standard not-found feedback if missing or unpermitted.
