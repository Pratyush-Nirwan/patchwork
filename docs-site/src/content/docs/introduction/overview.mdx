This page is for engineering leads, administrators, and developers evaluating or onboarding onto Patchwork.

## What Patchwork Is

Patchwork is an open-source (`AGPL-3.0`), self-hosted ticketing platform for multi-team engineering organizations. It runs natively on Windows and Linux using Node.js, PostgreSQL, and the official MinIO binary without Docker or container layers.

## Workspace Hierarchy

Patchwork organizes all work in a strict five-level hierarchy:

1. **Organization**: Top-level tenant holding teams, system settings, and org-wide admins.
2. **Team**: Engineering group (e.g., Platform Infrastructure) with team leads, members, and viewers.
3. **Project**: Codebase or product area owned by a team, identified by a short key (e.g., `TELE`, `INFRA`).
4. **Board**: Kanban board inside a project with configurable columns and optional Work-In-Progress (WIP) limits.
5. **Ticket**: Individual work item (`TELE-1`) with markdown description, priority, assignee, labels, comments, attachments, and GitHub/GitLab links.

## Roles Overview

- **Admin (`admin`)**: Organization-level administrator with full access to all teams, boards, users, and System Configuration (`/dashboard/system`).
- **Team Lead (`lead`)**: Manages team members, projects, boards, and Kanban columns within assigned teams.
- **Member (`member`)**: Creates, edits, moves, and comments on tickets, uploads attachments, and links GitHub/GitLab items. Optional `developer` or `tester` sub-roles gate specific workflow column transitions.
- **Viewer (`viewer`)**: Read-only access to browse teams, boards, tickets, and attachments.

See the generated [Roles & Permissions Matrix](/reference/roles-and-permissions/) for exact action rules.

## High-Level Architecture

```
Browser (Next.js App Router + SSE /api/events)
   │
   ├──► Next.js Server (Node.js)
   │       ├──► PostgreSQL 16+ (Drizzle ORM, FTS tsvector + GIN, LISTEN/NOTIFY)
   │       └──► MinIO Binary (S3-compatible presigned upload & download URLs)
   │
   └──► Direct browser PUT/GET to MINIO_PUBLIC_URL (presigned URLs)
```

## Expected Result

After reading this page, you understand how Patchwork structures organizations, enforces roles, and separates relational state (PostgreSQL) from binary attachments (MinIO).

## Glossary

- **Admin Setup Token**: A one-time, AES-256-GCM encrypted token generated by `npm run setup` to unlock the browser Setup Wizard at `/setup`.
- **WIP Limit**: Maximum ticket count configured on a Kanban column; exceeded columns show a visual warning gauge.
- **Presigned URL**: Time-limited S3 URL signed with `MINIO_PUBLIC_URL` so browsers upload and download attachments directly from MinIO.
- **SSE (Server-Sent Events)**: Persistent HTTP stream at `/api/events` delivering real-time board mutations.
