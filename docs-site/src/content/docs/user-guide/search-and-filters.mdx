## Opening Search

Press `Ctrl+K` (Windows/Linux) or `Cmd+K` (macOS), or click the search bar in the top header.

## What Search Indexes

Patchwork searches across:

- Ticket keys (`TELE-1`), titles, and descriptions
- Ticket comments
- Extracted text inside `.pdf`, `.txt`, `.md`, `.csv`, and `.json` attachments

Results return ranked matches with highlighted snippets.

## Structured Filter Tokens

Combine free-text queries with filter tokens in Search mode:

- `in:<PROJECT_KEY>` — Scope to a project (e.g., `in:TELE`)
- `status:"In Progress"` — Match column name
- `priority:urgent` — Filter by priority (`urgent`, `high`, `medium`, `low`, `none`)
- `assignee:me` or `assignee:@name` — Filter by assignee
- `label:bug` — Filter by label
- `due:overdue` — Tickets past their due date
- `has:attachments` — Tickets with uploaded files

## Expected Result

Typing any query or filter token immediately returns matching tickets, boards, projects, teams, people, and labels.
