## Authentication & Session Model

- **Passwords**: Hashed with `argon2id`. Complexity rules are enforced server-side from `SecuritySettingsSchema`.
- **Sessions**: Stored in PostgreSQL (`sessions`), delivered via `HttpOnly` cookies, and validated against both `expiresAt` and optional `sessionIdleTimeoutMs`.
- **CSRF Protection**: State-changing API requests require a matching `x-csrf-token` header checked against the session's `csrfToken`.
- **Authorization**: Every route verifies organization and team RBAC roles server-side (`src/lib/rbac.ts`).

## Admin Setup Token & `TOKEN_ENCRYPTION_KEY`

During installation, `scripts/setup.mjs` encrypts the one-time Admin Setup Token with `AES-256-GCM` using `TOKEN_ENCRYPTION_KEY` and deletes the ciphertext as soon as `/setup` verifies it. Never regenerate `TOKEN_ENCRYPTION_KEY` while an unconfirmed setup token is pending.

## File Upload Validation & Headers

- Uploads validate MIME type, extension, and byte size against `StorageSettingsSchema` and `MAX_ATTACHMENT_BYTES`.
- Exported filenames pass through `sanitizeFilename()`.
- Security headers (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, etc.) are applied across responses.

## Reporting a Vulnerability

See `SECURITY.md` at the repository root: do not file public issues for security bugs. Open a private GitHub Security Advisory or email `security@example.com`.

## Binary Download Verification

When the installer downloads MinIO (`RELEASE.2025-09-07T16-13-09Z`), it enforces fail-closed verification:

- Downloads only over **HTTPS** (honoring `HTTPS_PROXY` and `NO_PROXY`).
- Displays binary name, size, and source URL for user confirmation before downloading (unless `--yes` / `--non-interactive` is passed).
- Fetches the official `.sha256sum` file over HTTPS, streams into a `.part` file inside `./data/cache/`, verifies byte length and SHA-256 digest, and **deletes any mismatched or truncated file** before copying to `./bin/`.
- Never executes an unverified binary and re-verifies cached binaries against `.sha256sum` before reuse.
