## Contributing

1. Read `CONTRIBUTING.md` and `AGENTS.md` in the repository root.
2. Set up your native environment ([Local Setup](/documentation/development/local-setup/)).
3. Keep documentation and `CHANGELOG.md` updated in the same change.
4. Run `npm run docs:check`, `npm run docs:build`, `npm run lint`, `npm run typecheck`, `npm run test`, and `npm run build` before submitting a pull request.

## Security Reports

Report vulnerabilities privately as described in `SECURITY.md`.
