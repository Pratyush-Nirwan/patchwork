## Known Limitations in v0.8.1-beta

The following capabilities are **not yet available in v0.8.1-beta** and are tracked in the v1.0.0 roadmap above:

- **Inbound GitHub and GitLab webhooks**: Planned for v1.0.0 ([Git and Developer Integrations](#git-and-developer-integrations)).
- **Email-to-ticket intake**: Planned for v1.0.0 ([Git and Developer Integrations](#git-and-developer-integrations)).
- **Standalone audit log viewer**: Planned for v1.0.0 ([Security, Audit, and Operations](#security-audit-and-operations)).
- **Personal API tokens (PATs) and public REST API**: Planned for v1.0.0 ([Git and Developer Integrations](#git-and-developer-integrations)).
- **2FA, passkeys, and SSO / OAuth login**: Planned for v1.0.0 ([Security, Audit, and Operations](#security-audit-and-operations)).

### Out of Scope (Not on the Roadmap)

- **Docker / container images**: Patchwork is intentionally native-only on Windows and Linux.
- **Native desktop or mobile apps**: Patchwork is a responsive web application for desktop and mobile browsers.
