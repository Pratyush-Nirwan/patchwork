This guide is for the initial administrator unlocking a new Patchwork installation at `/setup`.

## Prerequisites

- Patchwork installed and running (`npm run setup`)
- One-time **Admin Setup Token** printed by the installer

## Autosave & Resume

Every step saves automatically into PostgreSQL (`setup_state`). You can close `/setup` and resume later without losing progress.

## Wizard Steps

1. **Token Verification**: Enter the one-time Admin Setup Token. Rate limiting protects this endpoint from brute-force attempts.
2. **Admin Account**: Set the initial administrator's name, email, and strong password.
3. **Organization**: Configure the organization name, URL slug, and description.
4. **Teams**: Create one or more engineering teams and assign team leads.
5. **Employees & CSV Import**:
   - Add members manually or upload a CSV file (download the sample CSV template directly from the wizard).
   - Choose **name-based** (`FirstL@1234`) or **cryptographically random** initial temporary passwords. All imported accounts have `mustChangePassword` enabled on first login.
   - Toggle optional table columns (such as Projects or Role Notes) to simplify entry.
6. **Projects & Boards**: Create initial projects (with uppercase keys such as `INFRA`) and Kanban boards with custom columns and WIP limits.
7. **Review & Complete**: Finalize setup, lock `/setup`, and download the generated **members CSV**.

<Aside type="caution">
The downloaded members CSV contains plaintext temporary passwords (`setup_credentials` is cleared after completion). Store it in a secure password manager or encrypted share and delete the local file after onboarding your team.
</Aside>

## Expected Result

`/setup` locks permanently once completed (`setup_state.isCompleted = true`), and subsequent visits redirect to `/` where your organization workspace is ready.

## Troubleshooting

- **Duplicate email rejected during CSV import**: Emails are normalized case-insensitively (`lower(email)`). Remove duplicate rows and re-upload.
- **Locked out after losing token**: Run `node scripts/setup.mjs --action=reset` to start fresh.
